# ⏳ 모두의 타임캡슐 (Everyone's Time Capsule)

> 연수 마지막 5분, 단순 만족도 조사 대신 **"다음 주 내 교실에서 실천할 단 하나의 Re-design 원칙"**을 서약하고, 미래의 나에게 보내는 편지를 예약하는 웹 애플리케이션입니다.
>
> **프론트엔드**: GitHub Pages (HTML5, CSS3, Vanilla JS)  
> **백엔드**: Google Apps Script (V8) + Google Sheets  
> **자동 메일 발송**: Gmail API (`MailApp`) + Apps Script 시간 기반 트리거

---

## 🌟 주요 특징 및 원칙

1. **서약문(공개)과 편지(비공개) 철저 분리**
   - 참가자가 작성한 실천 서약문과 별명은 강의장 대형 화면(서약문 월)에 실시간으로 공유됩니다.
   - **이메일 주소, 편지 제목, 편지 본문은 월(Wall) API 응답에서 완전히 제외**되어 본인 외에는 누구도 열람할 수 없습니다.
2. **발송일 2가지 모드 (추천 실천일 & 직접 선택)**
   - `추천 실천일(ADMIN)`을 선택한 참가자의 타임캡슐은 **발송 시점에 세션의 `defaultSendAt`을 실시간 참조**하므로, 강사가 추후 일정을 변경하더라도 자동으로 반영됩니다.
3. **발송 완료 후 개인정보 영구 파기 (Purge)**
   - 발송 완료(`SENT`) 즉시 시트에 기록된 이메일 주소와 편지 본문을 자동으로 비우는 옵션을 제공하여 개인정보 유출을 원천 방지합니다.
4. **중복 발송 방지 및 일일 발송 한도 관리**
   - `LockService`로 동시성 잠금 처리
   - 발송 전 상태를 `SENDING`으로 먼저 변경
   - 1회 실행당 최대 30건 제한 (GAS 6분 타임아웃 방지)
   - `MailApp.getRemainingDailyQuota()`를 통해 일일 쿼터 소진 시 다음 날로 자동 이월
5. **감성적인 인터랙션 및 연출**
   - 모바일 최적화 스텝형 위저드 및 실시간 서약문 문장 완성 미리보기
   - 은하수 별빛 배경의 대형 화면 서약문 월(Wall)
   - 잔잔한 BGM 시스템 (음원 파일 없을 시 브라우저 내장 Web Audio API 앰비언트 신시사이저 폴백 가동)
   - 강사 마무리 멘트 전체 오버레이 연출 (`CLOSING Phase`)

## 📁 프로젝트 파일 구조

```
모두의 타임캡슐/
├─ index.html            # 참가자 모바일 작성 화면 (?s=세션코드)
├─ wall.html             # 서약문 월(Wall) 대형 스크린 화면 (?s=세션코드)
├─ admin.html            # 관리자 대시보드 화면
├─ css/
│  └─ style.css          # 공통 디자인 시스템, 애니메이션, 모바일/다크 테마
├─ js/
│  ├─ config.js          # GAS 웹앱 URL 및 클라이언트 설정
│  ├─ api.js             # fetch 래퍼 (CORS 회피 text/plain POST 전송)
│  ├─ participant.js     # 참가자 작성 화면 단계별 폼/미리보기 제어
│  ├─ wall.js            # 월 화면 증분 폴링, 별빛 배경, BGM, 마무리 연출
│  └─ admin.js           # 세션 관리, QR 생성, 즉시 발송, 트리거 제어
├─ gas/                  # Google Apps Script 백엔드 코드
│  ├─ Code.gs            # doGet/doPost 라우터, 시트 초기화 setup()
│  ├─ Config.gs          # 시트명, 헤더 매핑, 제약 상수
│  ├─ Auth.gs            # 관리자 비밀번호 검증 및 세션 토큰 관리
│  ├─ Sessions.gs        # 세션 CRUD, 대시보드 통계
│  ├─ Capsules.gs        # 서약문 제출, 서버 검증, 월 화면 조회 (개인정보 제외)
│  ├─ Mailer.gs          # HTML 편지 템플릿, 이스케이프, 메일 발송
│  ├─ Scheduler.gs       # 발송 처리 루프, 10분 주기 트리거 설치/삭제
│  ├─ Utils.gs           # 헤더 기반 시트 제어, KST 날짜, 수식 인젝션 방지
│  └─ appsscript.json    # 매니페스트 (Asia/Seoul, 권한 스코프)
└─ README.md
```

## 🚀 배포 가이드 (Step-by-Step)

### 1단계: Google 스프레드시트 생성 및 ID 복사
1. [Google Drive](https://drive.google.com/)에서 새 스프레드시트를 생성합니다. (예: `모두의타임캡슐_DB`)
2. 웹 브라우저 주소창에서 스프레드시트 ID를 복사합니다.
   - URL 형태: `https://docs.google.com/spreadsheets/d/`**`[여기가_SHEET_ID]`**`/edit`

### 2단계: Apps Script 프로젝트 생성 및 코드 등록
1. 스프레드시트 메뉴에서 **확장 프로그램** → **Apps Script**를 클릭합니다.
2. `gas/` 폴더 내의 파일들을 Apps Script 편집기에 각각 생성하여 붙여넣습니다:
   - `Code.gs`, `Config.gs`, `Utils.gs`, `Auth.gs`, `Sessions.gs`, `Capsules.gs`, `Mailer.gs`, `Scheduler.gs`
3. 좌측 톱니바퀴 아이콘(**프로젝트 설정**)을 누르고 **'appsscript.json' 매니페스트 파일 표시**를 체크한 뒤, 편집기로 돌아와 `appsscript.json` 내용을 `gas/appsscript.json` 내용으로 덮어씁니다.
4. **프로젝트 설정** 하단의 **스크립트 속성(Script Properties)**에 다음 2개의 속성을 추가합니다:
   - `SHEET_ID`: 1단계에서 복사한 스프레드시트 ID
   - `ADMIN_PASSWORD`: 관리자 대시보드 로그인에 사용할 비밀번호 (예: `mypassword1234`)

### 3단계: 초기 시트 세팅 (`setup()` 실행)
1. Apps Script 편집기 상단 함수 드롭다운에서 `setup`을 선택하고 **실행** 버튼을 누릅니다.
2. 최초 실행 시 구글 권한 승인 팝업이 뜹니다:
   - [권한 검토] → 계정 선택 → [고급] → [안전하지 않은 페이지로 이동] → [허용]
3. 실행 완료 후 스프레드시트를 확인하면 `Sessions`, `Capsules`, `Logs` 탭과 헤더가 자동으로 생성된 것을 볼 수 있습니다.

### 4단계: Apps Script 웹 앱 배포
1. Apps Script 편집기 우측 상단 **배포** → **새 배포**를 클릭합니다.
2. 유형 선택: **웹 앱(Web App)**
   - 설명: `모두의 타임캡슐 v1.0`
   - 다음 사용자로 실행: **나(내 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자(Anyone)** *(반드시 모든 사용자로 지정해야 참가자가 로그인 없이 접속 가능)*
3. **배포**를 누르고 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 5단계: 프론트엔드 환경 설정 (`js/config.js`)
1. 프로젝트 폴더의 `js/config.js` 파일을 열고, 4단계에서 복사한 웹 앱 URL을 붙여넣습니다:
   ```javascript
   var APP_CONFIG = {
     GAS_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
     ...
   };
   ```

### 6단계: GitHub Pages 호스팅
1. GitHub에 새 저장소(예: `time-capsule`)를 생성하고 코드를 푸시(Upload)합니다.
2. 저장소의 **Settings** → **Pages** 메뉴로 이동합니다.
3. **Source**: `Deploy from a branch` 선택, Branch: `main` / `/ (root)` 선택 후 **Save**를 누릅니다.
4. 몇 분 후 제공되는 GitHub Pages URL을 확인합니다.

## 🎯 현장 운영 매뉴얼

### 1. 연수 시작 전 (관리자 준비)
1. `admin.html`에 접속하여 스크립트 속성에 지정한 비밀번호로 로그인합니다.
2. **`+ 새 세션 생성`** 버튼을 누릅니다:
   - 세션명 입력 (예: `AIEDAP 모듈4 3기 연수`)
   - 추천 실천일 지정 (예: 다음 주 화요일 오전 9시)
   - 직접 날짜 선택 허용 여부 및 발송 후 개인정보 파기 여부 설정
3. 생성된 세션의 **`참가자 접속용 QR 코드`**를 다운로드하거나 강의 자료 슬라이드에 삽입합니다.
4. **[발송 및 스케줄러]** 탭에서 **`⚡ 10분 주기 트리거 설치`** 버튼을 클릭하여 자동 발송 스케줄러를 가동합니다.
5. **`서식 확인용 테스트 메일 발송`**을 통해 강사 이메일로 샘플 메일을 발송해 서식이 잘 오는지 확인합니다.

### 2. 연수 마무리 5분 (참가자 실천 서약)
1. 강의실 대형 스크린에 `wall.html?s=[세션코드]`를 전체화면으로 띄웁니다.
2. 화면 상단의 **`🎵 배경음악 시작`** 버튼을 눌러 부드러운 앰비언트 사운드를 재생합니다.
3. 참가자들에게 스마트폰으로 화면 우측 하단의 QR 코드를 스캔하도록 안내합니다:
   - 참가자는 **"동의 → 서약문 빈칸 채우기 → 미래의 나에게 편지 쓰기 → 발송일 확인 → 봉인"** 단계를 거칩니다.
4. 참가자가 봉인할 때마다 대형 스크린의 서약문 월에 새로운 타일이 부드럽게 반짝이며 실시간으로 채워집니다.

### 3. 강사 마무리 총평 (Closing Phase)
1. 강사는 관리자 화면(`admin.html`)에서 **`🎬 마무리 연출 켜기`** 버튼을 클릭합니다.
2. 대형 화면 전체가 어두워지며 주강사의 마무리 멘트가 묵직하고 감동적으로 강조 표시됩니다.
3. 연수 종료 후 **`📥 서약문 CSV 내보내기`**를 통해 참가자들의 익명 다짐 목록을 다운로드하여 보관할 수 있습니다.

## 🔒 보안 및 개인정보 처리 원칙

- **CORS Simple Request**: 프론트엔드에서 GAS로 전송 시 `Content-Type: text/plain;charset=utf-8`을 사용하여 CORS 프리플라이트 브라우저 오류를 사전에 방지했습니다.
- **수식 인젝션 차단**: 스프레드시트 기록 시 `=`, `+`, `-`, `@`로 시작하는 모든 사용자 입력은 앞에 `'`를 붙여 수식 실행을 방어합니다.
- **XSS 방어**: 월 화면 타일 및 이메일 HTML 생성 시 모든 텍스트는 HTML Entity 이스케이프 처리 후 출력됩니다.
- **자동 파기**: 예약 메일 발송이 성공하면 스프레드시트에 저장된 이메일 주소와 편지 본문이 즉시 삭제되어 잔존하지 않습니다.
